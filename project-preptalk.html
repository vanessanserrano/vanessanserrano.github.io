The Challenge

Problem

Interview prep is stressful and time-consuming. Candidates lack realistic practice, tailored questions, and actionable feedback in a single place—especially without mentors or mock-interview access.

Solution

PrepTalk analyzes a résumé, generates role/company-aware questions, and runs mock interviews (HR/Manager/Technical) with webcam and technical coding rounds—then returns structured feedback.

Research Insights

  • Candidates spend hours searching for “likely questions” yet get little personalized practice.
  • Students want concise company context (culture, values) before mock interviews.
  • Immediate, specific feedback (structure, tone, confidence) drives improvement.

Design Process

Flows

  • Interview Start → upload résumé, choose role/company, select round type
  • Prep Page → résumé feedback, company snapshot, practice tips
  • Interview → HR/Manager rounds or Technical editor with prompts

UI Priorities

  • Minimal layout, clear timers and prompts
  • High-contrast controls and large touch targets
  • Panelized feedback with examples and next steps

Development

Architecture

frontend/
  React + TypeScript (Vite, Tailwind)
  Pages: Home, InterviewStart, InterviewPrep, Interview, Technical
  Monaco editor for coding round
backend/
  FastAPI
  POST /api/parse_resume
  POST /api/generate_questions
  OpenAI JSON responses · résumé parsing (PyPDF2 / python-docx)

Highlights

  • Structured prompts for reliable JSON (questions, rubrics)
  • Webcam integration for live mock sessions
  • Monaco editor + local JS runner for technical tasks
  • CORS + endpoint testing via Postman before wiring UI

Key Features

Résumé-aware Questions

Generates HR/Manager/Technical prompts grounded in your actual experience and target role.

Company Prep

Concise summaries of culture, values, and example interview themes to prime candidates.

Mock Interviews

Webcam + timed sessions; structured rubrics for tone, clarity, and confidence.

Technical Round

Monaco editor with sample tests; JS local runner (extensible to TS/Python via backend).
