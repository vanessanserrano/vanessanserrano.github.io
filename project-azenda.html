Azenda — A Zen Approach to Time Management

Schedules tasks around energy and constraints; keeps planning clear and quiet.

Role UX Designer & Full-Stack Developer
Tools Figma, Next.js, Django REST API, GitHub
Timeline Fall 2025 · 10 weeks + ongoing
GitHub repository

On this page

Problem Solution Research User needs Wireframes & flow Visual design Development Iteration Impact & next

Problem space

  • Balancing academics, personal care, and wellness is difficult
  • General tools are complex or rigid
  • People know what to do, but not when to do it

Solution

Azenda auto-schedules tasks across 48 daily blocks, respecting sleep windows and preferred work times while keeping the UI minimal and legible.

Research & discovery

  • Four interviews
  • Competitive audit
  • Pain points: clutter, rigidity, low accessibility

User needs

NeedSolution in Azenda
Flexible scheduleAuto-scheduled tasks based on best times
Lower overwhelmSimple UI with clear priorities
Protect restSleep/wake settings reserved
Recurring itemsWeekly view with repeat rules

Wireframes & user flow

Key screens: Login, Dashboard, Interactive calendar (48 × 30-minute blocks), Add Task modal.

Visual design

  • Soft neutrals; accessible contrast
  • Sans-serif type; large targets
  • Subtle transitions

Development

Frontend: Next.js (App Router), CSS Modules.

Backend: Django REST API.
