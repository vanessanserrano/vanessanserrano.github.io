The Challenge

Problem

Standard map apps don’t optimize complex multi-stop errands with constraints like “A before B”, “arrive by 6pm”, or “insert fuel when below 15%”.

Solution

OptiPath composes constraint-aware ordering with traffic-dependent ETAs and fuel-range modeling, outputting clean links for native navigation apps.

Research Insights

  • Most users plan errands around fixed appointments and preferred sequences.
  • Traffic sensitivity matters more than shortest geometric distance.
  • Fuel anxiety is real — automatic refuel inserts reduce cognitive load.

Design Process

Key Flows

  • Enter/paste stops → Set leave/arrive → Optimize → Export
  • Enable fuel model → Add tank/MPG → Auto-insert refuel

UI Priorities

  • Map + stops list + route panel in one screen
  • Single primary CTA per step with clear status
  • High contrast green/white with accessible states

Development

Architecture

app/
  pages: Main, Settings, Fuel, Results
  components: MapComponent, StopsList, FuelSettings, ExportLinks
  services: distanceMatrix.ts, optimize.ts, fuelTracker.ts
  state: stops[], constraints, vehicle, profile

Highlights

  • Constraint-aware TSP heuristic with precedence mapping
  • Traffic via Google Distance Matrix (departureTime)
  • Fuel splice based on capacity/MPG/thresholds
  • Export builders for Google/Apple Maps URLs

Key Features

Constraint-aware Optimization

Respects A→B precedence and fixed endpoints in ordering.

Fuel-aware Routing

Models range and inserts refuel with Places/Text Search.

Time Targets

Leave/arrive times with traffic-aware ETAs; back-solve departures.

One-tap Export

Open optimized itineraries in Google or Apple Maps.
