ARC — Action, Resources, Care

Confidential support for first responders after high-intensity calls.

Project ShellHacks 2025 (36 hours)
Role UX Designer, Front-End Developer
Stack React Native (Expo), TypeScript, Flask, MongoDB, Auth0

Demo

GitHub repository

Overview

ARC provides post-call check-ins, access to resources, and confidential connections to therapists or peer mentors—reducing stigma and making support easier to reach.

Research

Surveyed 41 first responders to understand habits, comfort, and needs.

61% aware of resources but not using them
40% cite stigma or fear of judgment
78% rate the concept useful (3+/5)
Top requests: peer mentor chat and therapist scheduling. Pillars: confidentiality, speed, trust.

Design

  • User flows for onboarding, post-call check-ins, and resource access
  • Low-fidelity wires for check-ins, contacts, and library
  • High-fidelity prototypes (navy/orange palette, Poppins)
  • Accessibility: strong contrast and large touch targets
  • Heuristic reviews to validate tone and flow

Development

React Native front-end with Flask API; Auth0 for authentication; Expo Router for navigation.

  • Implemented Figma components in React Native
  • Prototype AI to analyze call transcripts and time check-ins

Outcome

  • Real-time post-call check-in flow
  • Confidential contact options (therapist, mentor, trusted contact)
  • AI-based severity cues and guided chat
  • Resource hub with curated materials

Next steps

  • Richer AI for nuanced emotion detection
  • Follow-up reminders after tough calls
  • Trusted contact notifications
  • Pilot with local fire/EMS departments
